# Прокат велосипедів - Архітектурне бюро
## Етап 1: Іменники й дієслова

### Іменники:
* Станція - Клас
* Велосипед - Клас
* Звичайний / Електричний велосипед - підклас
* Номер - Атрибут класу Велосипед
* Клієнт - Клас
* Ім'я - Атрибут класу Клієнт
* Баланс - Атрибут класу Клієнт
* Хвилина (час поїздки) - Параметр для методу розрахунку
* Звіт - Окрема функція в main

### Дієслова:
* Стоять (на станції) - Метод додавання/отримання велосипедів
* Взяти (велосипед) - Метод
* Покататись (рахувати час) - Метод
* Повернути (велосипед) - Метод
* Коштує (рахувати вартість) - Метод
* Списуються (гроші) - Метод
* Бачити звіт - Функція генерації звіту в main
