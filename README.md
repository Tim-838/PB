# Прокат велосипедів - Архітектурне бюро
## Етап 1: Іменники й дієслова

### Іменники:
* Станція - Клас
* Велосипед - Клас
* Звичайний / Електричний велосипед - підклас
* Номер - Атрибут класу Велосипед
* Клієнт - Клас
* Ім'я - Атрибут класу Клієнт
* Баланс - Атрибут класу Клієнт
* Хвилина (час поїздки) - Параметр для методу розрахунку
* Звіт - Окрема функція в main

### Дієслова:
* Стоять (на станції) - Метод додавання/отримання велосипедів
* Взяти (велосипед) - Метод 
* Покататись (рахувати час) - Метод
* Повернути (велосипед) - Метод
* Коштує (рахувати вартість) - Метод
* Списуються (гроші) - Метод
* Бачити звіт - Функція генерації звіту в main


## Етап 2: Картки класів

### Клас: Станція
  * Що знає (атрибути): назва, список велосипедів, які на ній стоять
  * Що вміє (методи): додати велосипед на станцію, видати велосипед (або повернути None, якщо немає), порахувати, скільки велосипедів стоїть

### Клас: Велосипед (звичайний)
  * Що знає (атрибути): номер
  * Що вміє (методи): сказати ціну за хвилину (2 грн), сказати, чи можна його видати

### Клас: Електричний велосипед (підклас Велосипеда)
  * Що знає (атрибути): номер
  * Що вміє (методи): сказати ціну за хвилину (5 грн), сказати, чи можна його видати

### Клас: Клієнт
  * Що знає (атрибути): ім'я, баланс
  * Що вміє (методи): списати гроші з балансу (повертає True, якщо вистачило грошей, і False, якщо ні)

### Клас: Поїздка (сервіс прокату)
  * Що знає (атрибути): загальна виручка мережі
  * Що вміє (методи): видати велосипед клієнту зі станції, порахувати вартість (хвилини × ціна за хвилину), прийняти велосипед на станції і списати гроші з клієнта, додати гроші до виручки

### Окрема функція: звіт адміністратора
  * Що робить: друкує, скільки велосипедів на кожній станції і скільки мережа заробила загалом

## Етап 3: Розподіл файлів та ролей

* **Роль 1: ** - файл `station.py` Усе, що стосується велосипедів і станцій
* **Роль 2: ** - файл `client.py` Усе, що стосується клієнта та його балансу
* **Роль 3: ** - файл `rental.py` Логіка поїздки: взяти/повернути велосипед, порахувати вартість, облік виручки
* **Роль 4: ** - файл `main.py` Функція main(), створення тестових даних, генерація звіту
